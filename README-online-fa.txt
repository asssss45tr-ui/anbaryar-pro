انباریار پرو — نصب آنلاین (HTTPS) روی Render
=============================================
با این روش دیگر Termux لازم نیست؛ دوربین روی آدرس https کار می‌کند و همهٔ گوشی‌ها با یک آدرس همگام می‌شوند.

۱) یک مخزن (repository) جدید در GitHub بساز، مثلاً anbaryar، و همهٔ فایل‌های همین پوشه را در ریشهٔ آن آپلود کن
   (index.html, serve.py, sw.js, manifest.webmanifest, icons/, render.yaml).
۲) در render.com وارد شو → New → Blueprint → همان مخزن را انتخاب کن → Apply.
   (یا New → Web Service: Build Command: echo ok — Start Command: python serve.py $PORT)
۳) بعد از چند دقیقه آدرسی مثل https://anbaryar.onrender.com می‌دهد. آن را در Chrome باز کن.
۴) کد همگام‌سازی: Render → سرویس → Environment → مقدار ANBARYAR_KEY.
   در برنامه: تنظیمات → همگام‌سازی → آدرس را خالی بگذار، کد را وارد کن → اتصال.
   روی هر گوشی دیگر هم همین آدرس را باز کن و همین کد را بزن.
۵) در Chrome: منو ⋮ → «Add to Home screen» تا مثل یک برنامه نصب شود.

نکته‌ها
- نسخهٔ رایگان Render بعد از چند دقیقه بی‌کاری می‌خوابد؛ اولین باز شدن حدود یک دقیقه طول می‌کشد. داده‌ها داخل خود گوشی‌ها ذخیره‌اند و چیزی گم نمی‌شود.
- دیسک رایگان Render دائمی نیست؛ اگر سرور ریست شود، نسخهٔ سرور خالی می‌شود و با اولین اتصال گوشی‌ها دوباره پر می‌شود.
- آدرس جدید یعنی مرورگر جدید: داده‌های قبلی (localhost) خودکار منتقل نمی‌شوند. در برنامهٔ قدیمی: تنظیمات → پشتیبان → «پشتیبان JSON»، و در برنامهٔ جدید «بازیابی از فایل».
- اگر Render در اینترنت تو باز نشد، پوشه را روی GitHub Pages یا Cloudflare Pages هم می‌شود گذاشت (بدون همگام‌سازی، فقط HTTPS).
