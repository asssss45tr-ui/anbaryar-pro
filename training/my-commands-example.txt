# ═══════════════════════════════════════════════════════════
#  نمونهٔ «بستهٔ دستور» انباریار — فایل متنی ساده
#  با هر ویرایشگری (یا خود گوشی) عوضش کن و در برنامه:
#  دستیار ← 🧠 آموزش و دستورات ← «بارگذاری بسته»
#  قانون‌ها:
#   • خط‌هایی که با # شروع می‌شوند توضیح‌اند و خوانده نمی‌شوند
#   • هر بخش با ## شروع می‌شود
#   • هر مورد با «- » (خط تیره و فاصله) شروع می‌شود
#   • خطای یک خط، بقیهٔ فایل را خراب نمی‌کند؛ فقط همان خط گزارش می‌شود
#   • عبارت تکراری خودکار نادیده گرفته می‌شود
# ═══════════════════════════════════════════════════════════

## intent: stock_in        # ورود کالا
- بنداز تو انبار
- بریز تو قفسه
- برام بیار
- جنس رسید

## intent: stock_out       # خروج کالا
- بده بره
- بفروش
- از انبار بکش بیرون

## intent: stock_check     # بررسی موجودی
- چقدر داریم از
- هنوز مونده؟
- ته کشیده؟

## intent: profit          # فروش و سود
- امروز چقدر کار کردیم
- درآمد امروز

## intent: low_stock
- چی داره تموم میشه
- چی بخرم

## alias: شامپو              # اسم مستعار کالا (نام کالا باید در برنامه باشد)
- شامپوی سر
- شمپو

## macro                     # میانبر:  وقتی گفتم «چپ» یعنی «فاکتور جدید»
- چپ => فاکتور جدید
- ر ب => بار رسید

## reply                     # پاسخ ثابت (سؤال‌وجواب مغازه)
- ساعت کاری => شنبه تا پنجشنبه ۹ تا ۲۱
- شماره حساب => ۶۰۳۷-xxxx-xxxx-xxxx

## remove                    # فراموش کردن عبارت‌هایی که دیگر نمی‌خواهی (پیش‌فرض‌ها هم)
- کالا وارد شد

## qa                        # پرسش و پاسخ: بدون اینترنت جواب داده می‌شود
- ساعت کاری فروشگاه => شنبه تا پنجشنبه ۹ تا ۲۱
- آدرس مغازه => خیابان … پلاک …
